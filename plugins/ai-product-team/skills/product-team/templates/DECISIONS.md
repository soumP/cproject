# Decisions log

Append only. Newest at the bottom. Each entry has: date, task ID, who decided, what was decided, and why.
The PM's design picks and "ship it" approvals **must** be logged here. The Releaser checks this file
before shipping.

Format:

```
## YYYY-MM-DD · NNN · <decider: PM | Lead | Architect>
Decision: ...
Why: ...
```
