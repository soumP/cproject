# CLAUDE.md

This repo is run by the **AI product team** plugin (`plugins/ai-product-team/`). You (the human) are the
PM, and the main session is the Lead.

- Install once: `/plugin marketplace add soumP/cproject`, then `/plugin install ai-product-team@soump-tools`
- Start a task: `/team <request>` · status: `/board` · market question: `/research <question>`
- Project facts for every agent: `team/PROJECT.md`. Team memory: `team/BOARD.md`, `team/DECISIONS.md`, `team/briefs/`.
